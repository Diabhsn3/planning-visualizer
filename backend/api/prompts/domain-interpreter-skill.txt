You are an expert in automated planning (PDDL), TypeScript, and data visualization.

Your task is to generate a TypeScript **state transformer function** for a custom PDDL planning domain.

# BACKGROUND

A planning visualizer app runs a planner (Fast Downward) on PDDL problems and visualizes the resulting state sequences. For known domains (blocks-world, gripper, hanoi, etc.), hand-written renderers exist. For **custom/unknown domains**, the system uses a generic Python `DefaultRenderer` that produces flat, undecorated state data.

Your job is to write a TypeScript function that takes one of these flat raw states and transforms it into a fully enriched `RenderedState` — with positions, colors, labels, and layout — ready for a Canvas renderer to draw.

# ⭐ #1 GOAL — LAY OUT FOR FAITHFUL READBACK (read this first)

The renderer you feed can only be as legible as the positions you assign. Your #1 job is to lay objects out so a viewer of the FINAL IMAGE — a human OR a vision model — can reconstruct the EXACT set of true predicates, with correct identities. Aesthetics are strictly secondary.

CONTAINMENT, NOT CONNECTOR LINES. When a relation means located-in / at / on / holding / loaded / inside, the contained object must end up DRAWN INSIDE its container. You make that possible by:
- Positioning the contained object's [x, y] INSIDE its container's region (near the container, offset so multiple contents tile without overlap) — NOT at a far-away spot the renderer would have to connect with a line.
- Tagging the relation with `properties.relationship`: "contained" (`at`/`on` a place), "nested" (`in` a vehicle/container), or "edge" (a genuine peer link like connected/road/adjacent). Advisory only — the renderer also reads the relation `type`.
- Setting `properties.containerId` on the contained object to its container's id, so the renderer can nest it and grow the container to fit.

A line across the canvas between two distant glyphs reads as "near"/"connected" and often crosses unrelated containers, causing misattribution (an aircraft `at city2` read as `at city4`). Place the object INSIDE city2 instead.

EVERY OBJECT HAS A HOME; NOTHING FLOATS. Give every object a position inside a real region. An object with NO `at`/`in`/`on` relation this step must go to a dedicated "Unplaced" holding area (a reserved, labeled zone) — never parked on empty or decorative space. Do NOT invent virtual "band"/"lane"/"road"/"strip" objects to park items on.

2. **2–3 sample raw states** from ONE example problem (to help you understand the data format)

**CRITICAL**: The sample states are from a SINGLE small example problem. ## Requirements for the transformer function

1. **Parse raw.relations** to build relationship maps (e.g., `on[above] = below`, `at[obj] = location`)
2. **Compute positions** for every object — `position: [x, y]` is REQUIRED on every VisualObject
3. **Assign colors** — `properties.color` is REQUIRED on every VisualObject
4. **Make labels human-readable** — replace raw PDDL IDs with readable names (e.g., `"block1"` → `"Block 1"`)
5. **Preserve all relations** from the raw state in the output
6. **Handle any valid state** for this domain — the function must work for ANY problem with ANY number of objects
7. **Never hardcode object names or counts** — always iterate over `raw.objects` and `raw.relations` dynamically

## Layout Strategy

Choose the layout that matches the domain's natural visual metaphor:
- **Stacking** (`on ?x ?y`): vertical stacks, table at bottom (y ≈ 520), objects stack upward
- **Locations** (`at ?x ?loc`): divide canvas into location regions, objects inside their region
- **Graph/network** (`connected ?a ?b`): arrange nodes in grid or circle
- **Containers** (`in ?x ?container`): draw containers as rectangles, contents inside

### Worked layout — Locations & Transport (`at` / `in` / `on`)

The most common — and most often mis-laid-out — class (logistics, ferry, zenotravel, gripper, depot, …). When the domain has locations plus things that are `at` a location and possibly `in` a vehicle/container, compute positions like this:
1. Locations → a grid of large regions; give each a base `[x, y]` and `width`/`height` in `properties` so the renderer draws a labeled box.
2. An object `at` a location → a position INSIDE that location's region, offset by its index among the location's contents (tile, no overlap). Set `properties.containerId` to the location id.
3. An object `in` a vehicle → a position INSIDE the vehicle's region (nested). Set `properties.containerId` to the vehicle id. If the vehicle is `at` a location, the passenger lands inside the location too: location ⊃ vehicle ⊃ passenger.
4. Tag each such relation with `properties.relationship` = "contained" (`at`/`on`) or "nested" (`in`).
5. Objects with no location → a reserved "Unplaced" region.
6. Keep the raw PDDL `type` on each VisualObject (e.g. `type: o.type`, role in `properties.role`) so the renderer can pick a recognizable ICON per type (plane, truck, ship, person…). Size vehicle/container boxes generously so a recognizable icon plus its contents fit.

See the "EXAMPLE OUTPUT (Transport / Locations Domain)" below for a complete reference transformer.

Canvas is **800 × 600** pixels. Origin at top-left. Y increases downward.

## Stability Rules

- Positions must be **deterministic** — same object → same area across states
- Colors must be **deterministic** — same object → same color across states
- **Never use `Math.random()`**
- Derive positions from object index in a sorted list, not from current state values
- The function must work for problems with 2 objects or 200 objects — scale layout dynamically

# EXAMPLE OUTPUT (Blocks World Domain)

Here is a perfect example of a complete transformer. Study the structure carefully:

```typescript
// Inline interface declarations
interface RawRelation { type: string; source: string; target?: string; properties?: Record<string, any>; }
interface RawObject { id: string; type: string; label: string; properties?: Record<string, any>; }
interface RawState { domain: string; objects: RawObject[]; relations: RawRelation[]; metadata?: Record<string, any>; }
interface VisualObject { id: string; type: string; label: string; position: [number, number]; properties: { color: string; [key: string]: any; }; }
interface VisualRelation { type: string; source: string; target?: string; properties?: Record<string, any>; }
interface RenderedState { domain: string; objects: VisualObject[]; relations: VisualRelation[]; metadata?: Record<string, any>; }

const BLOCK_COLORS = ["#FF6B6B","#4ECDC4","#45B7D1","#FFA07A","#98D8C8","#F7DC6F","#BB8FCE","#85C1E2","#F39C12","#2ECC71"];
function getBlockColor(id: string): string {
  const lower = id.toLowerCase();
  let index = lower.length === 1 && lower >= "a" && lower <= "z"
    ? lower.charCodeAt(0) - 97
    : lower.split("").reduce((s, c) => s + c.charCodeAt(0), 0);
  return BLOCK_COLORS[index % BLOCK_COLORS.length];
}
function makeLabel(id: string): string {
  if (id.length === 1) return id.toUpperCase();
  const m = id.match(/^([a-zA-Z_-]+?)[\s_-]?(\d+|[A-Z])$/);
  if (m) return m[1].charAt(0).toUpperCase() + m[1].slice(1).toLowerCase() + " " + m[2];
  return id.charAt(0).toUpperCase() + id.slice(1);
}

const BLOCK_SIZE = 60;
const TABLE_Y = 520;
const GRIPPER_Y = 60;

export function transformBlocksWorld(raw: RawState): RenderedState {
  const blocks = raw.objects.filter(o => o.type === "block");
  const on: Record<string, string> = {};
  const ontable = new Set<string>();
  const clear = new Set<string>();
  let holdingBlock: string | null = null;
  let handEmpty = false;

  for (const rel of raw.relations) {
    if (rel.type === "on" && rel.target) on[rel.source] = rel.target;
    else if (rel.type === "ontable") ontable.add(rel.source);
    else if (rel.type === "clear") clear.add(rel.source);
    else if (rel.type === "holding") holdingBlock = rel.source;
    else if (rel.type === "handempty") handEmpty = true;
  }

  const onTopOf: Record<string, string> = {};
  for (const [above, below] of Object.entries(on)) onTopOf[below] = above;

  const tableBlocks = Array.from(ontable).sort();
  const stacks: string[][] = [];
  for (const bottom of tableBlocks) {
    const stack = [bottom];
    let cur = bottom;
    while (onTopOf[cur]) { cur = onTopOf[cur]; stack.push(cur); }
    stacks.push(stack);
  }

  const usableWidth = 800 - 80;
  const stackSpacing = stacks.length > 0 ? usableWidth / (stacks.length + 1) : usableWidth / 2;
  const positions: Record<string, [number, number]> = {};

  stacks.forEach((stack, si) => {
    const sx = 40 + stackSpacing * (si + 1);
    stack.forEach((id, hi) => { positions[id] = [sx, TABLE_Y - BLOCK_SIZE / 2 - hi * BLOCK_SIZE]; });
  });

  if (holdingBlock) positions[holdingBlock] = [400, GRIPPER_Y + BLOCK_SIZE];

  blocks.map(b => b.id).sort().forEach((id, i) => {
    if (!positions[id]) positions[id] = [40 + (i + 1) * (800 / (blocks.length + 1)), TABLE_Y - BLOCK_SIZE / 2];
  });

  const visualObjects: VisualObject[] = [];
  for (const block of blocks) {
    const isHeld = block.id === holdingBlock;
    visualObjects.push({
      id: block.id, type: "block", label: makeLabel(block.id),
      position: positions[block.id],
      properties: { color: getBlockColor(block.id), width: BLOCK_SIZE, height: BLOCK_SIZE,
        clear: clear.has(block.id), held: isHeld, zIndex: isHeld ? 10 : 1,
        status: isHeld ? "held" : clear.has(block.id) ? "clear" : "stacked" }
    });
  }
  visualObjects.push({ id: "__table__", type: "surface", label: "Table",
    position: [400, TABLE_Y + 10], properties: { color: "#8B4513", width: 760, height: 20, zIndex: 0 } });
  visualObjects.push({ id: "__gripper__", type: "gripper",
    label: handEmpty ? "Hand (empty)" : "Hand (holding " + holdingBlock + ")",
    position: [holdingBlock ? 400 : 740, GRIPPER_Y],
    properties: { color: "#607D8B", empty: handEmpty, holding: holdingBlock, zIndex: 20 } });

  return {
    domain: raw.domain,
    objects: visualObjects,
    relations: raw.relations.map(r => ({ type: r.type, source: r.source, target: r.target, properties: r.properties })),
    metadata: raw.metadata,
  };
}
```

# EXAMPLE OUTPUT (Transport / Locations Domain)

Use THIS template for ANY domain with `at` / `in` / `on` location relations (logistics, ferry, zenotravel, gripper, depot, …). It classifies objects by ROLE inferred from the relation target TYPES (a "location" is any object whose TYPE appears as an `at` target; a "vehicle" is any object whose TYPE appears as an `in` target; everything else is a "mover" — using the *type* means a location with nothing at it right now is still drawn as an empty box, not dumped into "Unplaced"), lays locations out as a grid of boxes plus an "Unplaced" box, positions every contained object INSIDE its container's box (tiled, no overlap), and tags `containerId` / `relationship` so the renderer draws containment — never lines.

```typescript
interface RawRelation { type: string; source: string; target?: string; properties?: Record<string, any>; }
interface RawObject { id: string; type: string; label: string; properties?: Record<string, any>; }
interface RawState { domain: string; objects: RawObject[]; relations: RawRelation[]; metadata?: Record<string, any>; }
interface VisualObject { id: string; type: string; label: string; position: [number, number]; properties: { color: string; [key: string]: any; }; }
interface VisualRelation { type: string; source: string; target?: string; properties?: Record<string, any>; }
interface RenderedState { domain: string; objects: VisualObject[]; relations: VisualRelation[]; metadata?: Record<string, any>; }

const PALETTE = ["#4E79A7","#F28E2B","#59A14F","#E15759","#B07AA1","#76B7B2","#FF9DA7","#EDC948","#9C755F","#499894"];
function hashId(id: string): number { let h = 0; for (let i = 0; i < id.length; i++) h = (h * 31 + id.charCodeAt(i)) >>> 0; return h; }
function colorFor(id: string): string { return PALETTE[hashId(id) % PALETTE.length]; }
function makeLabel(id: string): string {
  const m = id.match(/^([a-zA-Z_-]+?)[\s_-]?(\d+|[A-Z])$/);
  if (m) return m[1].charAt(0).toUpperCase() + m[1].slice(1).toLowerCase() + " " + m[2];
  return id.charAt(0).toUpperCase() + id.slice(1);
}

const CANVAS_W = 800;
const CANVAS_H = 600;
const UNPLACED = "__unplaced__";

function tileSlots(n: number, box: { x: number; y: number; w: number; h: number }, topPad: number) {
  if (n <= 0) return [] as Array<{ cx: number; cy: number; cw: number; ch: number }>;
  const cols = Math.max(1, Math.ceil(Math.sqrt(n)));
  const rows = Math.ceil(n / cols);
  const innerX = box.x + 6, innerY = box.y + topPad, innerW = box.w - 12, innerH = box.h - topPad - 6;
  const cw = innerW / cols, ch = innerH / rows;
  const out: Array<{ cx: number; cy: number; cw: number; ch: number }> = [];
  for (let i = 0; i < n; i++) { const c = i % cols, r = Math.floor(i / cols); out.push({ cx: innerX + c * cw + cw / 2, cy: innerY + r * ch + ch / 2, cw, ch }); }
  return out;
}

export function transformTransport(raw: RawState): RenderedState {
  const typeOf: Record<string, string> = {};
  for (const o of raw.objects) typeOf[o.id] = o.type;
  const atOf: Record<string, string> = {};
  const inOf: Record<string, string> = {};
  const locationTypes = new Set<string>();
  const vehicleTypes = new Set<string>();
  for (const r of raw.relations) {
    if (r.type === "at" && r.target) { atOf[r.source] = r.target; if (typeOf[r.target]) locationTypes.add(typeOf[r.target]); }
    else if (r.type === "in" && r.target) { inOf[r.source] = r.target; if (typeOf[r.target]) vehicleTypes.add(typeOf[r.target]); }
  }
  const role = (id: string): "location" | "vehicle" | "mover" =>
    locationTypes.has(typeOf[id]) ? "location" : vehicleTypes.has(typeOf[id]) ? "vehicle" : "mover";

  const realLocations = raw.objects.filter((o) => role(o.id) === "location").map((o) => o.id).sort();
  const places = [...realLocations, UNPLACED];

  const cols = Math.max(1, Math.ceil(Math.sqrt(places.length)));
  const rows = Math.ceil(places.length / cols);
  const margin = 20, pad = 10;
  const cellW = (CANVAS_W - margin * 2) / cols, cellH = (CANVAS_H - margin * 2) / rows;
  const placeRect: Record<string, { x: number; y: number; w: number; h: number }> = {};
  places.forEach((pid, i) => {
    const c = i % cols, r = Math.floor(i / cols);
    placeRect[pid] = { x: margin + c * cellW + pad, y: margin + r * cellH + pad, w: cellW - pad * 2, h: cellH - pad * 2 };
  });
  const placeOf = (id: string): string => (atOf[id] && placeRect[atOf[id]] ? atOf[id] : UNPLACED);

  const directContents: Record<string, string[]> = {};
  const passengers: Record<string, string[]> = {};
  for (const pid of places) directContents[pid] = [];
  for (const o of raw.objects) {
    if (role(o.id) === "location") continue;
    if (role(o.id) === "mover" && inOf[o.id]) { (passengers[inOf[o.id]] = passengers[inOf[o.id]] || []).push(o.id); }
    else { directContents[placeOf(o.id)].push(o.id); }
  }

  const positions: Record<string, [number, number]> = {};
  const sizes: Record<string, { w: number; h: number }> = {};
  for (const pid of places) {
    const items = directContents[pid].slice().sort();
    const slots = tileSlots(items.length, placeRect[pid], 26);
    items.forEach((id, i) => {
      const s = slots[i];
      positions[id] = [s.cx, s.cy];
      if (role(id) === "vehicle") {
        const vw = Math.max(64, Math.min(s.cw - 10, 170)), vh = Math.max(48, Math.min(s.ch - 10, 110)); // room for a vehicle icon + passengers
        sizes[id] = { w: vw, h: vh };
        const vbox = { x: s.cx - vw / 2, y: s.cy - vh / 2, w: vw, h: vh };
        const plist = (passengers[id] || []).slice().sort();
        const pslots = tileSlots(plist.length, vbox, 18);
        plist.forEach((pid2, j) => { positions[pid2] = [pslots[j].cx, pslots[j].cy]; });
      }
    });
  }

  const objects: VisualObject[] = [];
  for (const pid of places) {
    const rect = placeRect[pid];
    const unplaced = pid === UNPLACED;
    objects.push({
      id: pid, type: unplaced ? "unplaced" : "location", label: unplaced ? "Unplaced" : makeLabel(pid),
      position: [rect.x + rect.w / 2, rect.y + rect.h / 2],
      properties: { color: unplaced ? "#9aa0a6" : colorFor(pid), role: "location", width: rect.w, height: rect.h, unplaced },
    });
  }
  for (const o of raw.objects) {
    const rl = role(o.id);
    if (rl === "location") continue;
    const pos = positions[o.id] || [CANVAS_W / 2, CANVAS_H / 2];
    if (rl === "vehicle") {
      const sz = sizes[o.id] || { w: 90, h: 60 };
      objects.push({ id: o.id, type: o.type, label: makeLabel(o.id), position: pos, properties: { color: colorFor(o.id), role: "vehicle", width: sz.w, height: sz.h, containerId: placeOf(o.id) } }); // keep raw type (e.g. "aircraft") for icon choice
    } else {
      objects.push({ id: o.id, type: o.type, label: makeLabel(o.id), position: pos, properties: { color: colorFor(o.id), role: "mover", radius: 16, containerId: inOf[o.id] || placeOf(o.id) } });
    }
  }

  const relations: VisualRelation[] = raw.relations.map((r) => ({
    type: r.type, source: r.source, target: r.target,
    properties: { ...(r.properties || {}), relationship: r.type === "in" ? "nested" : r.type === "at" ? "contained" : "edge" },
  }));

  return { domain: raw.domain, objects, relations, metadata: raw.metadata };
}
```
